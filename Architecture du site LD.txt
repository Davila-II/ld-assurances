# Projet LD Assurances SA – Feuille de route

## 1. Backend – Laravel

En grande partie réalisé

- Créer le projet Laravel.
- Configurer la base de données SQLite.
- Créer les migrations.
- Créer les modèles : Category, FormField, Submission, Attachment et User.
- Définir les relations entre les modèles.
- Créer les catégories d'assurance initiales.
- Configurer les questions dynamiques des formulaires.
- Créer les API pour récupérer les catégories.
- Créer les API pour récupérer les formulaires.
- Créer l'API d'enregistrement des déclarations.
- Ajouter la validation des données.
- Générer automatiquement les références des déclarations.
- Enregistrer les réponses en JSON.
- Conserver une copie de la structure du formulaire utilisé.
- Enregistrer les pièces jointes.
- Configurer une limitation du nombre de requêtes.
- Sécuriser définitivement le stockage et le téléchargement des documents.
- Ajouter une gestion complète des erreurs et des journaux.
- Préparer les migrations et la configuration pour la base de données de production.

## 4. Gestion des devis d'assurance

- Identifier les produits d'assurance qui ne disposent pas encore de formulaire de devis sur le site actuel.
- Ajouter les catégories concernées : Habitation, Santé, Responsabilité civile et autres produits à confirmer.
- Concevoir les formulaires de demande de devis.
- Configurer les questions selon chaque produit.
- Définir les règles tarifaires avec LD Assurances.
- Développer le calcul automatique uniquement lorsque les tarifs et règles sont officiellement validés.
- Effectuer les calculs côté backend.
- Générer les propositions de devis en PDF.
- Envoyer les devis par e-mail.
- Permettre aux administrateurs de traiter les demandes manuellement lorsque nécessaire.

Important : les formulaires de devis déjà présents sur le site actuel, notamment Automobile et Voyage, doivent rester intacts. Notre nouvelle plateforme ne doit pas les remplacer.

## 8. Constructeur de formulaires dynamiques

C'est une fonctionnalité particulièrement importante de notre projet.

L'administrateur devra pouvoir modifier les formulaires sans intervention d'un développeur.

- Ajouter une question.
- Modifier le libellé d'une question.
- Choisir le type de champ.
- Définir si la question est obligatoire.
- Ajouter des choix pour les listes déroulantes.
- Configurer les conditions d'affichage.
- Modifier l'ordre des questions.
- Désactiver une question.
- Activer ou désactiver une catégorie.
- Prévisualiser le formulaire avant publication.
- Conserver l'historique des formulaires utilisés.
- Empêcher la suppression définitive des questions déjà utilisées dans des déclarations.
