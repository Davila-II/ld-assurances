2. OÙ EN EST LE PROJET
----------------------

TERMINÉ
- Site public : devis + déclaration de sinistre, design harmonisé (couleurs,
  Montserrat, header/footer, page devis reproduits d'après le site original).
- Devis : 4 formulaires locaux (Habitation, Santé, Responsabilité civile, Autres)
  + 3 liens sortants vers le site original (Auto, Voyage, Professionnelle).
- Déclaration de sinistre : formulaire général adaptatif (8 types), 4 étapes,
  consentement + signature, délai légal affiché, exemples (placeholders).
- Emails : confirmation au client, notification à l'admin, changement de statut,
  réponse au client.
- Suivi de demande par référence (page publique).
- Espace client (interface) : connexion, inscription, tableau de bord,
  mes demandes/sinistres/contrats/documents, profil (sans vraie authentification).
- Back-office : tableau de bord, liste avec filtres (statut, type, catégorie,
  type de sinistre, recherche), fiche détaillée, changement de statut,
  observations internes, réponse client, pièces jointes.
- Constructeur de formulaires dynamiques (catégories + questions).
- Tests backend : 28 tests (74 assertions), tous verts.

RESTE À FAIRE
- Espace client : vraie authentification (inscription/connexion) + données
  réelles rattachées au compte.
- Constructeur : prévisualisation avant publication + historique de versions.
- Tests frontend (Vitest / Testing Library) — non configurés.
- Déploiement : hébergement, base de production, configuration SMTP réelle
  (le mail est actuellement en mode "log"), HTTPS, sauvegardes.
